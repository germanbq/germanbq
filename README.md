# Hi, I'm Germán Bravo Quintián

I'm a software developer interested in full-stack development, backend systems and well-structured applications. My projects combine web interfaces, relational databases and server-side logic, using technologies such as TypeScript, Java and PostgreSQL.

## Featured projects

### [NBA Stats](https://github.com/germanbq/estadisticas-baloncesto)

A full-stack basketball application for exploring players, teams and games, comparing statistics and saving personal favourites.

- Next.js, React and TypeScript, with Clerk authentication and PostgreSQL.
- Layered backend with controllers, services and repositories, using parameterised SQL queries.
- Relational data modelling, database functions and triggers for statistical aggregates.
- Tests using Vitest and Playwright.

[Visitar página web](https://estadisticas-baloncesto.vercel.app/)

*In development. Uses sample or simulated statistics.*

### [Pretty Woman](https://github.com/germanbq/pretty_woman)

A digital product catalogue for a haircare and cosmetics shop in Madrid.

- Built with Astro, TypeScript and Tailwind CSS.
- Product search, filtering and sorting, with navigation by brand and product type.
- Prerendered pages and reusable components for browsing the catalogue.

[Visitar página web](https://pretty-woman.pages.dev/)

*Initial version live, with more products to be added to the catalogue.*

### [Gold2Win](https://github.com/germanbq/Gold2Win)

An academic web application that simulates a betting platform, with custom betting formulas, dynamic odds and event-based chat.

- Java, Spring Boot, Spring Security, JPA and Thymeleaf.
- WebSockets for live chat and odds updates.
- User roles, administration tools and a simulated wallet without real payments.

### [Software Engineering Project](https://github.com/germanbq/Proyecto-ISll)

An academic Java management application backed by MySQL, covering requirements analysis, software design and implementation.

- Requirements specification, use cases and domain modelling.
- UML class and sequence diagrams.
- Application code, database scripts and JUnit tests.
